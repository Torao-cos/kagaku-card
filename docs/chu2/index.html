中2化学 テスト対策カード

使い方

  • 問題の面をタップ → 答えが1つずつ開く（ヒント）
  • 答えの面をタップ → 答えが全部出る。もう一度タップ、または左にスワイプ → 次のカード
  • 右にスワイプ → 前のカードに戻る（押し直しできる）
  • 頻度調整（はじめはON）：「覚えた」を押したカードは出にくくなり、2回続けて押すと出なくなる。押さずに次へ進むと元に戻る。試験前に全部見たいときはOFFに

ホーム画面に追加すると、アプリのように開けます（ブラウザのメニューから「ホーム画面に追加」）。
