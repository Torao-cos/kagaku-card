# 元素記号・化学式カード

中学生向けの暗記用フラッシュカード（スマホブラウザ・単一HTML・サーバなし）。
赤シートのように「答えを隠して → タップで少しずつ開く」だけの学習加速ツールです。クイズ形式ではありません。

- 仕様の正本: [`SPEC.md`](SPEC.md)
- データ（唯一の編集箇所）: [`data/cards.csv`](data/cards.csv)

## 使い方（学習者）

1. 出題範囲（元素記号 Lv1〜5／化学式 Lv1〜4）を選んで「はじめる」
2. 問題の面をタップ → 答えが1単位ずつ開く（ヒント）／答えの面をタップ → 全部出る／もう一度タップ → 次へ
3. 左スワイプで次へ、右スワイプで前へ（○×の押し直しもできる）
4. 「頻度調整」（はじめはON）では ○× で出る回数が変わり、2回続けて○にしたカードは「覚えた」になって出なくなる（タップで次へ進むと × 扱い）。試験前はOFFにすると全部出る

進捗は端末（localStorage）にだけ保存されます。サーバもログインもありません。

## リストを変える（管理者）

```sh
# 1) data/cards.csv を編集する（category,level,name,symbol,note）
#    または owner 書式のテキストから変換して追記:
node tools/import-list.js 化学式 新しいリスト.txt --append

# 2) 検証 → テスト → ビルド → デプロイ を1コマンドで
npm run ship
```

- カードIDは `category:name:symbol` の内容ベース。行の並べ替え・追加・削除で学習履歴は壊れません
- 元素記号の誤字（実在しない記号）、括弧の不一致、重複行はビルド前に機械的に弾かれます
- 生徒側への反映は「次の次の起動」（Service Worker の stale-while-revalidate）

## 開発

```sh
npm test          # エンジンの決定論テスト（tokenizer / 統合 / 卒業 / クールダウン / 重み）
npm run build     # dist/ 生成（検証NGなら生成しない）
npm run serve     # http://localhost:8787/ でローカル確認
```

構成: `src/engine.js`（純関数エンジン）／`src/app.html`（UIテンプレート）／`src/sw.js`／`build.js`／`tools/`
